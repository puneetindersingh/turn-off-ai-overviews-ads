# Privacy Policy — Clean SERP

**Last updated: 2026-06-02**

Clean SERP does not collect, store, transmit, or sell any personal data.

- **No analytics or telemetry.** The extension makes no network requests of any kind.
- **No remote code.** All code is bundled in the extension package.
- **Local settings only.** Your two toggle preferences (Hide Ads / Hide AI Overviews) are stored using `chrome.storage.sync`, which Chrome may sync between your own signed-in devices. This data never reaches the developer or any third party.
- **Limited scope.** The extension runs only on Google Search results pages and only modifies what is displayed on those pages.

Because no data is collected, there is nothing to access, export, or delete beyond uninstalling the extension (which clears its stored settings).

Questions: open an issue on the project repository.
